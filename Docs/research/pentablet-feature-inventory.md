# XP-Pen PenTablet 官方驱动功能清单（卸载前存档）

> 目的：卸载官方驱动（PenTablet 4.0.8）并把它有价值的功能移植进 TabletSketch 之前，
> 把官方驱动的**全部功能**记录在案，防止遗漏。信息来源：官方 UI 截图（9 张，2026-11-28）、
> `PenTablet.app/Contents/Resources/config.xml`、`language.ini`。
> 备份位置：`~/Desktop/PenTablet-backup-20261128/`（含整套应用、驱动、自启动 plist、设备配置）。

## 设备信息

- 设备：XP-Pen Deco 640（型号 LDN1302F-A），VID `0x28BD` / PID `0x2904`
- 驱动版本：PenTablet 4.0.8 (d0184bc)，bundleID `com.ugee.PenTablet`，常驻驱动 `com.ugee.PenTabletDriverPro`
- 笔：8192 级压感（官方仪表盘显示原始值 0~16383，双字节计）
- 板载键 8 个 + 笔侧键 2 个，无滚轮/触控/屏幕

## 一、板载键页（UI 第一页）

- 设备渲染图 + 顶部 8 个板载键卡片；点击卡片即弹出「热键设置」编辑该键
- 出厂默认绑定（键盘快捷键）：

| 键 | 默认动作 | 官方 Actid |
|---|---|---|
| 1 | B（画笔） | 27 |
| 2 | E（橡皮） | 207 |
| 3 | `[`（笔刷缩小） | 209→[ |
| 4 | `]`（笔刷放大） | — |
| 5 | Command + `-`（缩小） | — |
| 6 | Command + `+`（放大） | — |
| 7 | Command + Z（撤销） | — |
| 8 | Command + Shift + Z（重做） | — |

- 页面底部「工作区域」按钮进入映射设置
- 右上角：眼睛图标（预览/隐藏绑定标签）、循环箭头（恢复默认）

## 二、热键设置弹窗（每个键可绑定一类动作）

四类动作，任一键可选其一：

1. **快捷键**：键盘组合键，最多 20 组（如 `B`、`Ctrl+Z`），带撤销输入/清空按钮
2. **鼠标控制**：修饰键（Shift / Control / Option / Command / Space）+ 动作（单击 / 双击 / 中键单击 / 右键单击 / 滚轮向上 / 滚轮向下），可自定义命名
3. **其他**（驱动级功能）：
   - 显示驱动面板（呼出 PenTablet 主界面）
   - 无作用
   - 切换显示器（多屏间切换映射）
   - **精细模式**（按住时光标移动降速，便于精确点击）
   - **B|E**（画笔↔橡皮来回切换）
   - **笔/橡皮擦**（切换）
   - 滚动
4. **执行程序**：浏览选择一个可执行文件，按键启动它

每个弹窗底部：恢复默认 / 取消 / 确定。

## 三、笔设置页（UI 第二页）

- **压感曲线编辑器**：网格 + 贝塞尔曲线，两个可拖控制点（默认 0.5/0.5 即线性）；
  右侧 5 个预设曲线按钮（线性 / 软 / 硬 / 中凹 / 中凸 之类形状）
- **笔压开关**：关闭后压力恒定（线宽不随力度变化）
- **侧锋开关**（Tilt）：启用笔倾斜影响笔刷
- **鼠标模式开关** + 速度滑条（慢↔快）：笔变相对移动的鼠标（相对坐标模式，config.xml `RelativeCoords Speed="5"`）
- **当前压感实时仪表盘**：0~16383 原始压力实时显示

## 四、通用设置页（UI 第三页）

- **导出配置文件 / 导入配置文件**（配置档 JSON/XML）
- **诊断工具**（采集设备/驱动状态信息）
- **反馈**（跳官网）
- **恢复默认**
- 提示信息开关、快捷键总开关（关掉后所有板载键/侧键不发动作）

## 五、工作区域（映射设置）

- **屏幕区域**：所有屏 / 指定显示器 / 全屏 / 手动框选屏幕区域 / 屏幕标识 / 屏幕比例锁定
- **板面区域**：全手写区域 / 用笔点击两点框选板面有效区
- **旋转**：0° / 90° / 180° / 270°（`TabletPannel Orientation`）
- 显示屏设置 / 屏幕校准（仅手绘屏，Deco 640 无屏）

## 六、config.xml 完整参数（比 UI 更细的底层参数）

| 参数 | 默认值 | 含义 |
|---|---|---|
| ScreenMapping SX/SY/SW/SH | 0,0,0,0 | 屏幕映射区域（0=全屏） |
| TabletPannel TX/TY/TW/TH + Orientation | 0（全板面） | 板面映射区域与旋转 |
| Pen P0 / P2 | 0 / 1 | 压感曲线端点（输入起点/终点裁剪） |
| Pen P1X / P1Y | 0.5 / 0.5 | 压感贝塞尔控制点（0.5/0.5=线性） |
| DisablePressure | 0 | 笔压开关 |
| DisableSlope | 0 | 侧锋开关 |
| RelativeCoords Speed | 0 / 5 | 鼠标相对模式与速度 |
| MoveInTablet / PenMoveInTablet | 0 / 4 | 板内指针跟随模式 |
| PenBtn0/1/2 Actid | 27 / 207 / 209 | 笔侧键动作（下笔尖/侧键1/侧键2） |
| DevicePenNum / DeviceKeyNum | 8 / 8 | 笔压级数 / 板载键数 |
| DisableInfo / DisableQuickKey | 0 | 提示开关 / 快捷键总开关 |

## 七、language.ini 中存在但 Deco 640 用不上的功能（其它型号）

- 滚轮/触控：滚轮模式、鼠标模式、灯亮度（TR.Ring / TR.Touch / TR.Light）
- 触控功能组：缩放、滚动、笔刷大小、旋转
- 电池电量（无线型号）
- Windows Ink（Windows 专用）

| 官方功能 | TabletSketch 现状 | 计划 |
