# 压感曲线移植方案（备选，未实现）

> 状态：**已调研、已定稿方案，暂不实现**。官方驱动已卸载，压感曲线是其唯一不可替代的功能；用户评估后认为当前手感可接受，决定先放一放，等手感不顺手时再按本方案实施。

## 为什么值得保留这份方案

- 这是 XP-Pen 官方驱动唯一“系统没有、我们也还没有”的能力（其余要么已覆盖、要么已判定不做，见 `pentablet-feature-inventory.md`）。
- 实现在**纯前端**：采集器已经上报原始压力（`rawPressure`），曲线只是把 0..1 的压力重映射一次，不动 Swift、不动 HID 协议，风险低。
- 升级后默认参数可以做到**观感不变**，属于“加了也不打扰”的增强。

## 现状（不实现时的行为）

`Web/sketch/src/tablet-sketch.js` 的 `shapePressure()`：

```js
const PRESSURE_FLOOR = 0.35;
lifted = 0.35 + 0.65 * Math.pow(p, 0.6);
```

固定幂函数 + 0.35 下限，保证“轻触必出线”。用户无法调整。

## 方案要点

### 数据（`layout.v2` 新增 `pen` 段）

```js
pen: {
  pressureEnabled: true,
  curve: { x1: 0.35, y1: 0.45, x2: 0.6, y2: 0.95 }
}
```

进 `normalizeLayout` 校验（四个值 clamp 到 0..1，`x1 > x2` 时交换），自动获得配置档、导入导出、恢复默认。

### 数学

三次贝塞尔，端点固定 `(0,0)` / `(1,1)`，用户只拖两个控制点。输入压力当 x，二分 12 次反解 t 再取 y：

```js
x(t) = 3(1-t)²t·x1 + 3(1-t)t²·x2 + t³
y(t) = 3(1-t)²t·y1 + 3(1-t)t²·y2 + t³
```

输出仍套下限，保持“轻触必出线”：

```js
out = 0.35 + 0.65 * bezierY(p)
```

### 预设（默认“标准”要复现现有 `p^0.6` 观感）

| 预设 | (x1,y1) | (x2,y2) |
|---|---|---|
| 标准（默认） | 0.35, 0.45 | 0.60, 0.95 |
| 线性 | 0.333, 0.333 | 0.667, 0.667 |
| 柔和（轻压就粗） | 0.50, 0.72 | 0.78, 0.96 |
| 硬朗（要更用力） | 0.22, 0.10 | 0.55, 0.50 |
| 极硬 | 0.30, 0.03 | 0.68, 0.30 |

### UI（设置 → 绘图 → 笔）

`240×240` SVG：网格 + 曲线 + 两个可拖控制点（`pointerdown/move/up`，支持笔），下方 5 个预设按钮，一个「笔压」开关，一条实时压感显示（订阅已有 `tablet:penpos` 的 `raw` / `p`，仅本页挂载时订阅）。

拖动中只更新本地态，`pointerup` 才写配置，避免高频写 localStorage。

### 笔压开关

关闭时输出恒定 `0.55`（不用 0.5：Excalidraw 把 0.5 当作“无压感设备”的标记）。

## 实现清单（照做即可）

1. `layout-config.js`：`PRESSURE_PRESETS`、`normalizePen`、`bezierPressure`，`defaultLayout` 与 `normalizeLayout` 接入。
2. `tablet-sketch.js`：`shapePressure` 改读配置，监听 `tablet:layout` 即时生效。
3. `SettingsWindow.jsx`：新增 `PenPage`（曲线编辑器 + 开关 + 实时压感），替换现有 `pen` 页里那两个**从未被消费的死设置**（`pressureGamma` / `minStrokeWidth`）。
4. `chrome.css`：曲线编辑器与仪表盘样式。
5. 回归：曲线数学纯函数（单调性、端点、默认手感近似）+ 笔页渲染 + 离屏全量。

## 顺带发现的死代码

设置「笔」页现有的「压感曲线 gamma」和「最小线宽」两个滑条**没有任何代码消费**，且它们的存储键正是 `tablet.settings.v1`——`loadLayout()` 会主动删掉这个键。实施本方案时应一并删除。
