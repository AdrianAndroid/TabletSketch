# Design · window-as-pad

## 版式

```
┌──────────────────────────────────────────────────────┐
│ 未命名画板 · 手写笔   ○ ○ ○ ○ ○ ○ ○ ○    ● 手写板已连接 │  22pt 上排
│                      ↑ 板载键（常态不可见）            │  42pt 键区
├──────────────────────────────────────────────────────┤  64pt 合计
│ ╭──────────────────────────────────────────────────╮ │
│ │                                                  │ │  8pt 上边距
│ │            手写区 = 画布（浅灰 #f5f7fa）           │ │  12pt 左右下边距
│ │                                                  │ │  radius 14
│ ╰──────────────────────────────────────────────────╯ │
└──────────────────────────────────────────────────────┘
```

## 按键位置

真机板框 876×696，8 键中心 x = 173/267/360/454/546/639/731/824，板框左边界 60。归一化中心 = (x-60)/876：

`0.129 / 0.236 / 0.342 / 0.450 / 0.555 / 0.661 / 0.766 / 0.872`

用百分比 `left` + `translateX(-50%)`，窗口缩放时保持和真机一样的疏密。

## 映射

`tablet-sketch.js` 的 `applyHidEvent` 用 `canvasEl().getBoundingClientRect()` 作为映射矩形。把 Excalidraw 装进 `.ts-stage` 之后，这个矩形自动等于手写区，无需改映射代码 —— 这是选"窗口级版式"而不是"卡片内映射"的关键收益。

## 底色

`viewBackgroundColor` 由 `#ffffff` 改为 `#f5f7fa`，与 `.ts-stage` 同色，画布和手写区融为一体。`exportPNG` 已强制 `exportBackground: true` + `#ffffff`，导出不受影响。

## 取舍

- **不做 16:9 锁定**：锁定会让窗口出现大片留白，且用户已明确"板载区适配显示就行"，手写区按容器拉伸更符合"整窗就是板子"。
- **浮岛仍在右侧浮层上**：会盖住手写区右边 40pt，但它可拖动换边、可收起，先保持。
