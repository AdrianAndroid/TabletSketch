### 板载键识别

板载 8 键通过 page 1（Generic Desktop）的 `Report ID 6` 键盘报告上报，按 `(modifier, keycode)` 组合识别。
识别结果以 `aux` 事件送上界面，下标 0–7 与物理键位一一对应。
识别必须是边沿触发：按住不放只发一次。

### 板载键可见反馈

按键带在该键按下时点亮对应位置 180ms。除高亮外不得再触发画布动作——动作由固件映射的原生快捷键完成。
