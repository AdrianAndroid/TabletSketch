# 修复手写笔笔画延迟与飞线

## 问题

用户真机反馈两件事：

1. 用笔写时有明显延迟，笔迹跟不上笔尖；
2. 写小字（如「笔」字）时笔画会「飞」——起笔和收笔之间只剩一条长直线，中间细节全丢。

同一张画布上用鼠标画则完全没有这两个问题。

## 根因

`Sources/TabletSketchCore/PenStateMachine.swift` 的 `Config.jitterTolerance = 0.35` 与 `tapMaxDistance = 3.5` 注释都写成「画布 pt」，但 `HIDReader.emitPen` 传给状态机的 `point` 是**归一化坐标**（x/y ∈ 0..1）。单位错配导致：

- 一个笔画内，凡是单帧位移 < 0.35 且累计位移 < 0.7 的采样点全部被 `return events` 丢弃；
- 写「笔」字这类小字时，整笔位移通常只有 0.05~0.2，所有中间帧都被吞掉，只剩 `began` + `ended`，Excalidraw 把两点直接连成一条长直线——这就是截图中的飞线；
- 笔画越长，前 70% 板宽的移动都没有中间点，视觉上就是「笔迹滞后、突然跳一大步」。

鼠标路径由 `mouse-input.js` 直接调 `feedPen → applyHidEvent`，**不经过 PenStateMachine**，所以没有这个延迟。这是笔与鼠标行为不一致的直接原因，按项目规则以笔为准修复。

## 目标

- 状态机阈值单位与传入坐标一致，不再吞掉真实笔画采样点；
- 笔迹实时跟随笔尖，小字不再被连成直线；
- 保留对量化噪声（坐标上报精度 1e-4）的过滤，避免重复点；
- 补 Swift 单元测试固化行为，确保后续不回归。
