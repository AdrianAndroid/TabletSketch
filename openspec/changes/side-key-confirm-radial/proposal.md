# 笔侧键作为样式环 / 工具环的确认键

## 问题

侧键 1 弹出样式环后，必须把笔尖**压在扇区上**才能选中取值；侧键 2 的工具环同理。悬停高亮已经能工作（探针实测：笔停在扇区上 `is-hover` 正确点亮），但再按一次侧键什么也不会发生——`Shell.jsx` 的侧键处理在环打开时被 `if (radialRef.current) return;` 整体丢弃。

用户想要两段式操作：按键弹环 → 笔尖移到扇区 → **再按同一个键确认**，效果等同笔尖按下该扇区。

## 目标

- 样式环打开时按键 1、工具环打开时按键 2，执行当前悬停扇区，走与扇区 `onClick` 完全相同的动作路径。
- 悬停在中心圆内或环外空白时按键，等同点击中心：一级样式环关闭、二级返回一级、「更多」外环返回内环、工具环关闭。
- 笔已离开感应区时不响应确认，避免按最后悬停位置误操作。
- 鼠标入口（右键 / `\` / 更多 / 菜单）打开的环，笔键也能确认当前高亮的扇区。
- 交叉按键无动作：样式环里按键 2、工具环里按键 1 都不产生效果，也不切换到另一个环。

## 非目标

- 不取消或替换笔尖点击扇区的原有方式，侧键只是多一条确认路径。
- 不改扇区布局、取值、悬停高亮、外环展开的视觉与行为。
- 不改侧键 3（橡皮）与板载键的行为。

## 影响

- `Web/sketch/src/tablet/RadialMenu.jsx`：通过 `confirmRef` 暴露「执行当前悬停扇区 / 中心」的函数。
- `Web/sketch/src/tablet/Shell.jsx`：环状态记录 `wheel` 类型；侧键处理在环打开时按类型调用确认函数；离板判断。
- `openspec/specs/pen-first-ui/spec.md`：样式环与工具环条款补侧键确认场景。
