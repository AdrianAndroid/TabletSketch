# 侧键 1 样式环：无选中时自动选中笔尖下的图元

## 问题

按笔侧键 1 呼出样式环时，要求画布上已经有选中图元。没选中就直接 toast「先选中图形」、样式环不打开。用户想直接把笔停在图元上按侧键 1 改它的样式，不用先用「选」工具点一下。

## 目标

- 无选中时按侧键 1，若笔尖下有图元，**自动选中该图元并立即打开样式环**，样式值取自新选中的图元。
- 笔尖下无图元时保持原行为：toast「先选中图形」，不打开样式环。
- 笔已离开板子、或笔尖压在自绘 UI（浮岛 / 面板 / 板载键条 / 设置窗）上时，不做自动选中，同样走原提示。
- 已有选中时不改变任何行为：样式环仍然直接打开并作用于现有选区。

## 非目标

- 不新增「未选中」态的样式环界面，不改样式环的扇区、取值与弹出壳。
- 不改未命中时的 toast 文案与行为。
- 不改侧键 2 工具环、鼠标入口（右键 / `\` / 更多 / 菜单）的既有语义。
- 不改默认键位映射。

## 影响

- `Web/sketch/src/tablet-sketch.js`：bridge 增加「按屏幕坐标拾取并选中图元」的方法。
- `Web/sketch/src/tablet/Shell.jsx`：`openRadial` 在无选中时先尝试拾取；维护笔是否在板上的状态。
- `openspec/specs/pen-first-ui/spec.md`：修改「鼠标样式环入口」的打开状态场景，样式环条款补自动选中场景。
