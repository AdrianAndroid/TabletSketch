# 设计

## 几何

手写区严格 16:9；按键带只做适配显示，不按真机比例缩。

```
┌──────────────────────────────────────┐
│  ①   ②   ③   ④   ⑤   ⑥   ⑦   ⑧     │  按键带 h=44
├──────────────────────────────────────┤
│                                      │
│            手写区 16:9                │  360 × 202.5
│                                      │
└──────────────────────────────────────┘
        宽 360，总高 246.5，圆角 14
```

按键圆心 x（相对卡片左边）：46 / 84 / 123 / 161 / 199 / 237 / 275 / 314，y = 22。
来源：真机图测得板框 876×696，键间距 93px、首键中心 x=173px，换算后按 360 宽铺开。

## 笔点

- 归一化 `nx, ny ∈ [0,1]` 映射进手写区内框（四周留 6pt），落笔时外圈 5pt→12pt。
- 采集侧已 clamp 到 `PenReport.maxX/maxY`，前端再 clamp 一次，保证不越界。

## 板载键

- 常态完全不可见，只保留 28pt 透明热区。
- 按下：22pt 圆，主色填充 + 白字数字 + 240ms 涟漪，180ms 后淡出。
- 同一时刻允许多键（各自独立），不互斥。

## 数据

```
{"t":"pen","x":0..1,"y":0..1,"ph":"hover|began|changed|ended","p":0..1}
{"t":"aux","keys":[0,3]}      // 板载键，0-based
```

`aux` 与 `side` 分开：`side` 是笔侧键（0/1/2 = 侧键1/侧键2/橡皮），`aux` 是板载 8 键。

## 未验证

`AuxReportParser` 假设 `bytes[2]` 是 8 位键位图，来源是逆向推测，未经真机确认。
若按下无反应，用 `--dump` 抓原始字节重新定字节偏移与位序。
