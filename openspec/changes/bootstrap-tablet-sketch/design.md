# 设计：TabletSketch 首个可运行版本

## 1. 目标与边界

本设计只覆盖 `bootstrap-tablet-sketch` 的首个可运行版本（P0）：

- 独立 macOS App，不依赖 `MacAppControlDeck`。
- 只读 HID，读取 Deco 640 的完整笔数据。
- 压感/倾斜/橡皮进入 Excalidraw 画布。
- 16:9 等比例画布，笔迹限制在画布内。
- 笔侧键 + 8 个板载键的基础映射。
- 鼠标模式保留，无设备自动回退。
- 不做系统级指针接管，不做 KEXT/DriverKit。

## 2. 总体架构

```text
┌─────────────────────────────────────────────────────────────┐
│                        TabletSketch.app                      │
│                                                             │
│  ┌──────────────┐    ┌──────────────┐    ┌───────────────┐  │
│  │ HID Reader   │───▶│ PenInput     │───▶│ CanvasMapper  │  │
│  │ (IOHIDManager)│    │ StateMachine │    │ 16:9 / crop   │  │
│  └──────────────┘    └──────┬───────┘    └───────┬───────┘  │
│                             │                     │          │
│                      ┌──────▼─────────────────────▼───────┐  │
│                      │        TabletInputBridge           │  │
│                      │  虚拟笔光标 / 压力 / 倾斜 / 按键     │  │
│                      └──────────────────┬─────────────────┘  │
│                                         │                    │
│  ┌──────────────────────────────────────▼─────────────────┐  │
│  │              WKWebView + Excalidraw 0.18.1             │  │
│  │  Resources/Sketch：离线 JS/CSS/字体/素材库              │  │
│  └──────────────────────────────────────┬─────────────────┘  │
│                                         │                    │
│  ┌──────────────────────────────────────▼─────────────────┐  │
│  │              Native UI Shell (AppKit/SwiftUI)          │  │
│  │  顶部细条 / 左侧工具轨 / 右侧属性抽屉 / 径向菜单        │  │
│  └──────────────────────────────────────┬─────────────────┘  │
│                                         │                    │
│  ┌──────────────────────────────────────▼─────────────────┐  │
│  │              Document Store                            │  │
│  │  ~/Pictures/TabletSketch/Sketches / 草稿 / 导出         │  │
│  └────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

分层原则：

1. **HID Reader 只负责读字节**，不碰 UI、不碰画布。
2. **PenInput 只负责状态机和标准化事件**，不直接生成笔迹。
3. **CanvasMapper 只负责坐标变换**，不判断工具。
4. **TabletInputBridge 负责把标准化事件送进 WebView**。
5. **UI Shell 只负责布局和控件**，不直接读 HID。
6. **Document Store 只负责文件**，不持有 WebView。

这样换输入设备、换 WebView、换 UI 布局时，互相不牵连。

## 3. HID 输入层

### 3.1 设备与通道

| 通道 | UsagePage / Usage | Report ID | 用途 | 本项目用法 |
|---|---|---|---|---|
| A | `1 / 2` Mouse | `9` | 系统鼠标、绝对 X/Y、压感 | 只作观察，不作为主输入 |
| B | `13 / 2` Digitizer | `7` | 标准笔/橡皮/InRange/压感/倾斜 | fallback / 对照 |
| C | `0xFF0A / 1` Vendor | `2` | 完整笔数据 + 8 板载键 | **主输入** |

首版以 C 通道为准。原因：完整笔数据、板载键和厂商扩展都在 C；A/B 由系统接管，数据不完整。

### 3.2 初始化

```text
Output Report (20 bytes):
02 B0 04 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
```

- 只在打开手写板模式/窗口时发送一次。
- 发送后等待 ACK；ACK 必须过滤：`0xB4 / 0xF2 / 0xF8 / 0xC0`。
- 未过滤 ACK 可能被当成坐标 `(0,0)` 的笔报告，导致光标跳左上角。
- 初始化失败时不要重试到卡死；提示用户并回退鼠标模式。

### 3.3 12 字节笔报告

| 字节 | 含义 | 处理 |
|---|---|---|
| `[0]` | `0x02` | 报告类型校验 |
| `[1]` | 状态位 | bit1/2 笔侧键、bit3 橡皮、bit4 Aux |
| `[2..3]` | X 低 16 | 小端 |
| `[4..5]` | Y 低 16 | 小端 |
| `[6..7]` | 压感 uint16 | `0..16383` |
| `[8]` | TiltX | signed byte |
| `[9]` | TiltY | signed byte |
| `[10]` | X 高 8 | 与 `[2..3]` 拼成 24 位 |
| `[11]` | Y 高 8 | 与 `[4..5]` 拼成 24 位 |

- MaxX `31998` / MaxY `17998`；坐标先归一化到 `0..1`。
- 未知长度/未知 Report ID 直接忽略。
- 所有解析函数必须是纯函数，便于用固定字节数组做单测。

### 3.4 Aux 报告与板载键

- Aux 报告 `[2]` 是 8 键位图；`[3]/[4]` 扩展；`[7]` 是协议预留滚轮方向。
- Deco 640 没有独立滚轮；`[7]` 是否有值待实测。
- 板载键按下/抬起要做去抖（建议 10–20 ms），避免一次按下触发多次。
- 按键映射只在 TabletSketch 前台生效，不注册全局热键。

### 3.5 三态识别

```text
IDLE
  │ 笔进入感应区
  ▼
HOVER          InRange=1, Tip=0, Pressure=0
  │ Tip 闭合
  ▼
CONTACT        Tip=1, Pressure≈0 或很小
  │ 压力超过死区，或开始移动
  ▼
DRAWING        Tip=1, Pressure>阈值
  │ 压力回落到释放阈值
  ▼
CONTACT
  │ Tip 抬起
  ▼
HOVER
  │ 离开感应区
  ▼
IDLE
```

规则：

- **悬停不落笔**，只画笔刷光标。
- **Tip 闭合即起笔**，不要等压力超过阈值，否则轻画会丢、起笔会延迟。
- 压力为 0 时线宽取下限；压力越大越粗。
- 起笔阈值与释放阈值分离（滞回），避免压力抖动导致笔迹断断续续。
- 点击 vs 笔画：Tip 闭合到抬起时间短、位移小于 3–5pt，视为点击；否则为笔画。

### 3.6 压感映射

```text
raw ∈ [0, 16383]
p = raw / 16383
p' = pow(p, gamma)          // gamma 默认 1.0，可在 0.6–1.4 调
width = wMin + (wMax - wMin) * p'
```

- `wMin` 不能为 0，否则轻画不可见；建议 1–2pt。
- `wMax` 由当前工具决定；橡皮用压力控制擦除半径。
- 压力映射按工具保存预设；首版至少支持「钢笔/马克笔/橡皮」三套。
- 倾斜：`atan2(tiltY, tiltX)` 得到笔锋方向；首版可选启用，不启用时不得阻塞笔迹。

### 3.7 输入仲裁

- 同一时刻只有一个源写画布。
- 笔在感应区或 Tip=1：手写板源优先。
- 鼠标移动：鼠标源立即接管，笔暂停写画布。
- 手写板用应用内虚拟笔光标；系统鼠标箭头保持独立。
- 笔在画布内时隐藏系统箭头；鼠标移动后恢复。
- 只转换 TabletSketch 窗口内的笔事件；窗口失焦时停止画布锁定。
- 官方驱动与自研输入不得同时运行；检测到冲突时提示用户只保留一个源。

## 4. 画布映射

### 4.1 默认比例

- 画布默认 16:9，与 Deco 640 有效区一致。
- 整块板映射到画布矩形，等比缩放，不留横向/纵向拉伸。
- 画布周围用深色留白 + 细边框，明确可画区域。

### 4.2 坐标变换

```text
u = (x - minX) / (maxX - minX)
v = (y - minY) / (maxY - minY)

px = canvas.x + u * canvas.width
py = canvas.y + v * canvas.height
```

- `u/v` 超出 `[0,1]`：画布锁定模式下直接丢弃；全窗口模式下允许指针在 UI 上，但不产生笔迹。
- 不允许 `px` 和 `py` 各自拉满不同比例；必须保持 `canvas.width / canvas.height = 16/9`。

### 4.3 4:3 / 1:1 画布

按目标比例 `R` 取最大居中子矩形：

```text
if tabletAspect > R:
    cropW = tabletH * R
    cropH = tabletH
else:
    cropW = tabletW
    cropH = tabletW / R
```

- 只映射裁切后的子矩形，剩余区域不响应笔迹。
- 越界事件丢弃，不夹边；夹边会让画布边缘出现拖尾。
- 画布 UI 上显示裁切边界，用户能看到有效区。

### 4.4 两种模式

| 模式 | 笔能到哪 | 笔迹范围 | 工具操作 | 适用 |
|---|---|---|---|---|
| 全窗口映射 | 整个窗口 | 仅画布矩形 | 笔可点工具栏 | 默认，最实用 |
| 画布锁定 | 仅画布矩形 | 仅画布矩形 | 径向菜单/板载键 | 沉浸绘图 |

- 全窗口映射必须做「笔迹裁剪」：坐标落在 UI 上时不画。
- 画布锁定只在 TabletSketch 前台启用；窗口失焦自动解除，避免点到背后 App。
- 画布锁定要有明显视觉提示（边框颜色/锁定图标）。

## 5. UI 设计

### 5.1 布局

```text
┌─────────────────────────────────────────────────────────┐
│ 画布名  16:9  [适应] [导出]                 [锁定] [⋯]  │ 32pt
├──────┬──────────────────────────────────┬───────────────┤
│      │                                  │               │
│ 工具 │             Canvas               │   属性抽屉     │
│ 轨   │                                  │   （可折叠）   │
│ 56pt │                                  │               │
│      │                                  │               │
├──────┴──────────────────────────────────┴───────────────┤
│ 缩放 100%   ·   压感 16384   ·   设备已连接             │ 24pt
└─────────────────────────────────────────────────────────┘
```

- 顶部 32pt 细条：画布名、比例、适应、导出、锁定、更多。
- 左侧 56pt 工具轨：选择、矩形、箭头、文字、便签、画笔、橡皮、更多。
- 右侧属性抽屉：颜色、线宽、透明度、压感曲线、图层/顺序（首版可简化）。
- 底部 24pt 状态条：缩放、压感值、设备状态。
- 落笔自动隐藏顶部/底部/侧栏；抬笔或笔靠近边缘 20pt 内恢复。
- 左手模式：工具轨和属性抽屉镜像；不改变画布坐标。

### 5.2 可点区域

- 主工具按钮 44–48pt；次要按钮不小于 40pt。
- 滑杆轨道高度不小于 6pt，滑块不小于 28pt。
- 下拉菜单改为大号分段按钮或弹出面板；避免 1px 细线和微小箭头。
- 所有可点区域加 hit slop；笔尖点按允许 2–4pt 误差。
- 不在笔尖附近弹小菜单；径向菜单以笔尖为中心，半径 80–120pt。

### 5.3 径向菜单

- 笔侧键 2 呼出；8 个扇区，最少 4 个可用。
- 默认扇区：选择、画笔、橡皮、矩形、文字、撤销、适应画布、更多。
- 选择后菜单关闭，不要求笔回到工具栏。
- 菜单打开时暂停笔迹；选完恢复。
- 支持左手模式镜像。

### 5.4 模式

| 模式 | 行为 | 默认 |
|---|---|---|
| 鼠标模式 | 现有鼠标布局，笔就是鼠标 | 无设备时自动 |
| 手写板舒适模式 | 大按钮、全窗口映射、笔迹裁剪 | 检测到设备时默认 |
| 手写板沉浸模式 | 画布优先、隐藏 chrome、画布锁定、径向菜单 | 用户手动 |

- 模式切换必须在菜单/画布内可见，不要求记快捷键。
- 模式状态本机保存；换机器不跟随账号同步。
- 检测不到设备时自动回退鼠标模式，并提示一次。

## 6. WebView 与 Bridge

### 6.1 资源加载

- 复用 `Resources/Sketch/index.html` 与 `assets/`。
- 使用自定义 scheme（例如 `tabletsketch://local/`）加载，避免 `file://` 的目录与模块限制。
- CSP 保持 `default-src 'self' data: blob:`，不请求外部 CDN。
- 离线资源路径要做路径穿越保护。

### 6.2 Bridge 接口

建议沿用主项目 `deckSketch` 的模式，但使用独立名字 `tabletSketch`：

```text
JS → Native:
  ready
  change(scene)
  copyRequested
  copyJSONRequested
  saveRequested
  newRequested
  boardSwitchRequested
  boardCreateRequested
  boardRenameRequested
  boardDeleteRequested
  penDebug(report)

Native → JS:
  initBoards(activeId, boardsJson, scene)
  activateBoard(...)
  updateBoards(...)
  loadScene(json)
  getScene()
  getAIJSON()
  exportPNG(scale, padding, background)
  showToast(text, kind)
  setPenPressure(value)
```

- 笔事件高频，不走 `WKScriptMessageHandler` 的 JSON 往返；优先用 `evaluateJavaScript` 批量注入或直接操作 WebView 的 pointer 事件。
- `callAsyncJavaScript` 返回值不可靠时，改用 `evaluateJavaScript` 读字符串；异步导出用 Promise + 轮询结果。
- 所有 JS 调用失败必须有回退：不崩溃、不丢当前场景。

### 6.3 压感注入

按优先级：

1. 如果 Excalidraw 的 freehand 接受 `pressure` 数组/`PointerEvent.pressure`，直接注入。
2. 如果不接受，包一层自定义 brush，用 `perfect-freehand` 或自有采样生成 `freedraw` 元素。
3. 如果都不行，保留原 freehand，压感只影响线宽预览，不阻塞其他功能。

首版必须先做 PoC 验证 1 或 2，再铺完整 UI。

## 7. 文档与存储

### 7.1 目录

```text
~/Pictures/TabletSketch/Sketches/
  index.json
  <board-id>.excalidraw
  <board-id>.png
~/Library/Application Support/TabletSketch/
  draft.excalidraw
  settings.json
  keymap.json
```

### 7.2 多画布

- `index.json` 保存 `id/title/createdAt/modifiedAt/elementCount`。
- 每个画布一个 `.excalidraw`，场景本体不塞进索引。
- 切换画布前先 `getScene()` 落盘当前画布；切换失败要恢复原画布。
- 新建/重命名/删除都要有确认与错误提示。
- 自动保存 1s 防抖；关闭窗口/切换画布立即 flush。

### 7.3 导入与兼容

- 可直接打开 `.excalidraw`。
- 打开主项目 `~/Pictures/MacAppControlDeck/Sketches` 的文件时，先复制到 TabletSketch 目录，再编辑。
- 不直接写主项目目录；不共享 `UserDefaults`/`buttons.json`。
- 导出 PNG/JSON 保持主项目格式，便于互操作。

### 7.4 原子写入

- 先写临时文件，再 `replaceItemAt`。
- 写失败提示用户并保留旧文件。
- 不静默覆盖；不删除用户原文件。

## 8. 应用生命周期与权限

- 独立 App，Bundle ID `com.zhaojian.TabletSketch`。
- 默认启动打开主窗口；常驻菜单栏时保留「打开画板」。
- 单实例：重复启动激活已有实例，不创建第二个 HID reader。
- 关闭窗口默认不退出 App（可由用户选择「关闭即退出」）；`Cmd+Q` 退出。
- HID 只在窗口打开或手写板模式开启时初始化；关闭窗口停止。
- 输入监控权限被拒：显示说明 + 回退鼠标模式；不反复弹窗。
- 不做全局 event tap，不改系统鼠标，不装系统扩展。

## 9. 测试策略

### 9.1 单元测试

- `PenReportParser`：固定 12 字节数组 → 坐标/压力/倾斜/按键。
- `PenStateMachine`：悬停/接触/下压/抬笔/抖动滞回。
- `CanvasMapper`：16:9、4:3、1:1、越界丢弃、窗口缩放。
- `PressureCurve`：0/中间/最大值、gamma、最小线宽。
- `ExpressKeyMap`：默认映射、持久化、恢复默认。
- `SketchBoardStore`：创建/切换/重命名/删除/恢复。

### 9.2 集成测试

- `Tools/DecoProbe.swift` 只读探针：确认 VID/PID、C 通道、报告长度。
- 实机：悬停不出墨、轻触起笔、重压变粗、抬笔结束。
- 实机：16:9 画布四角/中心映射准确；画布外不出墨。
- 实机：笔侧键、8 板载键各触发一次；不重复触发。
- 实机：拔插设备、窗口失焦、切换画布、保存失败提示。

### 9.3 回归边界

- 鼠标模式：画布、工具、导出、保存与主项目 UI 草图行为一致。
- 无设备：启动不卡、不弹权限、自动鼠标模式。
- 不修改主项目：本仓库测试不依赖 `MacAppControlDeck` 运行。

## 11. 已知限制

- Excalidraw 是 React/Web 布局，深度改 UI 成本高；优先 CSS + 外层覆盖层，不动内核。
- WKWebView 对压感/倾斜的原生支持需要实测；不能假设 PointerEvent 一定带 pressure。
- 只读 HID 可能受输入监控权限影响；权限被拒时只能回退鼠标。
- 8 个板载键需要 vendor 模式初始化；初始化失败时按键不可用。
- 画布锁定在窗口失焦时可能把笔点送到背后 App；必须自动解除。
- 官方驱动与自研输入同时运行时可能双事件；首版只保证单源。
- 首版只支持 Deco 640；其他型号需要新增 `TabletProfile`。
