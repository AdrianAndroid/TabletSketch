# 提案：TabletSketch 独立手写板画板

> 状态：立项 / bootstrap。本文只定义首个可运行版本的需求与边界，不代表已实现。
> change-id：`bootstrap-tablet-sketch`
> 日期：2026-11-26
> 目标设备：XP-Pen Deco 640

## Why

现有 `MacAppControlDeck` 的 UI 草图是鼠标优先的 Excalidraw 画板。手写板在上面只能当鼠标用，压感、倾斜、橡皮、板载键都没有被利用；如果直接在主项目里改输入链、UI 布局和窗口生命周期，会影响已经稳定的鼠标草图、按钮管理和发布流程。

因此需要把「手写板画板」做成独立仓库：

- 先验证 Deco 640 的只读 HID + 压感 + 画布映射是否可行；
- 不影响主项目现有功能；
- 资源与 `.excalidraw` 文件格式保持兼容，未来可合并，也可独立发布；
- 给后续开发一个明确的 OpenSpec 边界，避免边写边改、越写越耦合。

## What Changes

### 1. 新建独立 macOS 应用

- 应用名：TabletSketch
- Bundle ID：`com.zhaojian.TabletSketch`
- 独立窗口、独立 WebView、独立输入桥、独立偏好域
- 不依赖 `MacAppControlDeck` 的可执行代码
- 默认打开画板即可用；应用常驻菜单栏时保留「打开画板」入口

### 2. 只读 HID 输入层

- 读取 XP-Pen Deco 640 的厂商私有通道（UsagePage `0xFF0A` / Usage `1`，Report ID `2`）
- 初始化 Output Report：`02 B0 04 + 17×00`（20 字节）
- 过滤 ACK：`0xB4 / 0xF2 / 0xF8 / 0xC0`
- 解析 12 字节笔报告：
  - `[1]` 状态位（笔侧键、橡皮、Aux）
  - `[2..3]` X 低 16
  - `[4..5]` Y 低 16
  - `[6..7]` 压感 uint16（0..16383）
  - `[8]/[9]` TiltX/Y（sbyte）
  - `[10]/[11]` X/Y 高 8 位
- 区分悬停 / 刚接触 / 下压；Tip 开关负责接触，压力负责下压程度
- 不接管系统鼠标；只在 TabletSketch 窗口内使用虚拟笔光标
- 同一时刻只允许鼠标或手写板一个输入源写画布

### 3. 16:9 等比例画布

- 默认画布比例 16:9，与 Deco 640 有效区一致
- 平板坐标等比映射到画布矩形，居中；不允许 X/Y 各自拉满
- 笔迹只在画布内产生；越界事件丢弃，不夹边
- 提供「全窗口映射」与「画布锁定」两种模式
- 全窗口映射下笔可以点工具，但笔迹仍限制在画布内
- 画布锁定下笔不能离开画布，工具通过径向菜单/板载键操作

### 4. 笔优先 UI

- 画布优先布局：顶部细状态条、左侧 44–48pt 工具轨、右侧可折叠属性抽屉
- 落笔自动隐藏 chrome，抬笔或靠近边缘再显示
- 工具控制在 6–8 个，其余收进「更多」
- 所有可点区域加 hit slop；不做微小下拉和 1px 细线
- 笔侧键呼出径向菜单；8 个板载键做默认映射
- 左手模式：工具轨、属性抽屉镜像
- 保留鼠标模式，无手写板时自动回退

### 5. 草图文档与素材

- 复用 Excalidraw 0.18.1 离线资源与 16 组素材库
- 多画布独立保存，格式为 `.excalidraw`
- 默认目录 `~/Pictures/TabletSketch/Sketches`
- 草稿目录 `~/Library/Application Support/TabletSketch`
- 自动保存、原子写入、保存失败提示
- 支持 PNG/JSON 导出与剪贴板复制
- 打开主项目草图时复制一份，不直接覆盖原文件

### 6. 按键映射

- 8 个板载虚拟快捷键 + 2 个笔侧键，共 10 个可独立映射输入
- 默认映射：
  - 板载 1：撤销
  - 2：重做
  - 3：平移
  - 4：橡皮
  - 5：适应画布
  - 6：取色
  - 7：线宽
  - 8：导出
  - 笔侧 1：橡皮切换
  - 笔侧 2：径向菜单
- 映射持久化，可恢复默认；未知报告忽略

## Capabilities

### New Capabilities

- `pen-input`：HID 读取、三态识别、压感/倾斜、输入仲裁
- `canvas-mapping`：16:9 画布、等比映射、越界丢弃、画布锁定
- `pen-first-ui`：画布优先布局、大工具轨、径向菜单、左手模式
- `sketch-document`：多画布、`.excalidraw`、自动保存、导入导出、素材库
- `express-keys`：8 板载键 + 2 笔侧键、默认映射、持久化
- `app-lifecycle`：独立 App、入口、权限、无设备回退、单实例

### Modified Capabilities

- 无。主项目 `MacAppControlDeck` 不在本变更范围内。

## Impact

### 代码

- 新仓库，新建 App 目标、输入层、画布层、UI 层、存储层。
- 复用 `Resources/Sketch` 与 `Web/sketch` 源码，不直接复制主项目运行代码。
- `Reference/SketchModule` 只作参考，不加入编译。

### 权限

- 只读 HID 可能需要「输入监控」权限。
- 权限只在手写板模式开启或窗口打开时请求；拒绝后回退鼠标模式。
- 不新增辅助功能、屏幕录制、自动化权限，除非后续变更明确需要。

### 数据

- 新目录，不写主项目 `~/Pictures/MacAppControlDeck/Sketches`。
- 不共享主项目 `UserDefaults`、`buttons.json`、`devices.json`。
- 可导入/复制现有 `.excalidraw`，但不直接编辑原文件。

### 体积

- `Resources/Sketch` 约 5.7 MB；`Web/sketch` 源码约 2.5 MB。
- 不提交 `node_modules`、构建缓存、发布包。

### 对主项目

- 无代码、无运行时、无打包影响。
- 未来合并必须另建 OpenSpec 变更。

## 非目标

- 不做系统级手写板驱动，不接管系统鼠标。
- 不做 KEXT / DriverKit / SIP 关闭 / 开发者账号依赖。
- 不做 OCR 手写识别。
- 不做云同步、多人协作、Excalidraw 云服务。
- 首版不支持 Deco 640 以外的型号。
- 首版不做 Windows/Linux。
- 首版不做完整的专业绘画引擎（图层、笔刷引擎、色彩管理）。
- 首版不做全局快捷键抢占；板载键只在 TabletSketch 前台生效。

## 成功标准

首个可运行版本必须满足：

1. 接上 Deco 640，TabletSketch 能识别设备并显示压感笔迹。
2. 悬停不落笔；刚接触起笔；下压线宽变化；抬笔结束。
3. 16:9 画布内笔迹正常；画布外不产生笔迹；比例不变形。
4. 笔侧键可切橡皮/呼出径向菜单；8 个板载键至少完成默认映射。
5. 鼠标仍可正常使用；手写板不抢系统光标。
6. 拔掉手写板后自动回退鼠标模式，不崩溃。
7. 画布保存为 `.excalidraw`，重启可恢复；素材库离线可用。
8. 主项目 `MacAppControlDeck` 不受影响。

## 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| vendor 模式初始化失败 | 读不到完整笔数据 | 先用只读探针验证；失败回退标准 HID / 鼠标模式 |
| 压感注入 Excalidraw freehand 不稳定 | 线宽不跟手 | 先做 PoC；必要时自定义 brush，保留原 freehand |
| 输入监控权限被拒 | 无法读 HID | 明确提示；回退鼠标模式；不阻塞启动 |
| 官方驱动与自研输入同时跑 | 双事件/双光标 | 只保留一个事件源；检测到冲突时提示 |
| 画布锁定后窗口失焦 | 笔点落到背后 App | 只在 TabletSketch 前台启用锁定 |
| 掌压/侧键误触 | 误画/误操作 | 只认 Tip=1；边沿检测；按键去抖 |
| 两套 UI 维护成本 | 迭代变慢 | 鼠标模式保持原布局；手写板布局独立 variant |
