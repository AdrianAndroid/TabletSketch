# design · turn-radial-menu-into-style-wheel

## 1. 目标

侧键 1 从「动作菜单」变成「样式入口」：

```
选中图形 ──侧键1──▶ 内环 L1：样式类别
                     │ 笔尖点类别
                     ▼
                   内环 L2：取值（当前值高亮）
                     │ 笔尖点值
                     ▼
                 应用 + 关闭 + 300ms 浮条
```

当前层只有 1 项时跳过 L1，直接开取值环。

超过 10 项时，第 10 槽为「更多样式」，点开在**内环外侧再套一环**：

```
              外环：剩余项目（最多 10）
     ╭──────────────────────────────────────╮
     │   ⑪      ⑫      ⑬      ⑭      ⑮     │
     │      ╭──────────────────────────╮    │
     │  ⑩  │  ①   ②   ③   ④   ⑤   ⑥ │    │
     │ 更多 │                          │    │
     │      │         ◎ 返回            │    │
     │  ⑨  │  ⑧   ⑦                   │    │
     │      ╰──────────────────────────╯    │
     ╰──────────────────────────────────────╯
```

侧键 2 的行为不变；环打开时只是忽略它。

## 2. 交互定稿

| 场景 | 行为 |
|---|---|
| 有选中 + 侧键 1 | 以笔尖为圆心打开一级环 |
| 无选中 + 侧键 1 | 不打开，浮条提示「先选中图形」 |
| 笔尖正在画（tip down）+ 侧键 1 | 忽略，不打断笔画 |
| 环已打开 + 侧键 1 | 不响应 |
| 环已打开 + 侧键 2 | 忽略；环关闭时侧键 2 行为完全不变 |
| 鼠标右键 / `\` | 打开样式环（入口由 `add-mouse-input` 提供） |
| 手写板入口圆心 | 笔尖；笔尖已被限制在 `.ts-stage` 内 |
| 鼠标入口圆心 | 鼠标位置；鼠标不做任何限制 |
| 一级点类别 | 同一圆心切到二级环 |
| 二级点取值 | 立即应用并关闭 |
| 二级点中心 | 返回一级 |
| 一级点中心 / 点空白 | 关闭 |
| 按 Esc | 关闭 |
| 窗口失焦 / 缩放 / HID 断开 | 关闭 |
| 笔离开感应区 | 不关闭；只由用户动作或上述事件关闭 |
| 混合选中 | 取可用类别交集；>10 项时第 10 槽为「更多样式」 |
| 悬停 | 高亮落点扇区，并在环外显示「名称 + 当前值」 |
| 点「更多样式」 | 内环降为半透明不可点，外环展开剩余项 |
| 外环点类别 | 收起外环，内环切换成该类别二级取值 |
| 外环点中心「返回」 | 只收起外环，回到内环一级 |
| 应用失败 | 保留环，浮条提示失败原因 |

状态机：

```
closed ──侧键1──▶ inner.L1
inner.L1 ──点类别──▶ inner.L2
inner.L2 ──点取值──▶ closed（应用）
inner.L2 ──点中心──▶ inner.L1
inner.L1 ──点「更多样式」──▶ inner(0.4) + outer
outer ──点外环项目──▶ inner.L2
outer ──点外环中心──▶ inner.L1
inner.L1 ──点中心 / 空白 / Esc / 失焦 / 缩放 / 断连──▶ closed
```

### 3.4 归纳

- **基础图形（矩形 / 菱形 / 椭圆）**：7 个样式维度，另有图层、操作。
- **线类（直线 / 箭头）**：没有「边角」，换成「起点箭头 / 终点箭头」；箭头多一个 Arrow type。
- **自由笔**：颜色、背景、宽度、透明度。
- **文字**：颜色 + 字体 + 字号 + 对齐 + 透明度。
- **画框**：只有透明度。
- **嵌入网页**：与基础图形相同的样式行，操作行强调「链接」。

## 5. 取值定义

### 5.1 颜色

- 固定 6 个预设色：黑 `#1e1e1e`、红 `#e03131`、绿 `#2f9e44`、蓝 `#1971c2`、橙 `#f08c00`、灰 `#868e96`。
- 描边：6 个预设。
- 背景：6 个预设 + 无填充。
- 不提供自定义取色器、任意十六进制输入、调色板设置面板。
- 当前颜色不在预设内：不高亮任何色块，悬停提示显示真实色值。

### 5.2 字号与对齐

- 字号：S / M / L / XL，固定 4 档；不提供自定义步进器。
- 当前字号不在预设内：不高亮，提示显示真实值。
- 字体、对齐按 Excalidraw 实际可写枚举生成；截图只作参考。

### 5.3 透明度

8 档：`100 / 90 / 80 / 70 / 50 / 30 / 20 / 10`，去掉 0，避免元素完全消失。

### 5.4 端点

- 拆成「起点箭头」「终点箭头」两个类别，各自一个二级环。
- 取值按实际枚举：无 / 箭头 / 三角 / 竖线 / 圆点。
- 起点和终点可分别设置，不需要第三层环。

## 6. 扇区与环几何

### 6.1 内环

```
D1 = max(240, 180 + 15n)
R1 = D1 / 2
内径 = 45
中心圆直径 = 90
```

| n | 1–4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---:|---:|---:|---:|---:|---:|---:|
| D1 | 240 | 255 | 270 | 285 | 300 | 315 | 330 |
| R1 | 120 | 127.5 | 135 | 142.5 | 150 | 157.5 | 165 |

| 项数 | 渲染 |
|---:|---|
| 1 | 整个环就是一个选项，点任意位置即选中；此情况在 L1 会被跳过 |
| 2 | 上下两个半环 |
| 3 | 从 12 点起三等分 |
| 4 | 上 / 右 / 下 / 左 |
| 5–10 | 从 12 点起顺时针等分，图标保持正立 |

`n = 1` 与 `n = 2` 需要给 `sectorPath` 加特例：现有函数画不出整环，180° 圆弧的 `large-arc` 方向也不稳定。

### 6.2 外环

```
间隙 = 8pt
带宽 = 44pt
R2 = R1 + 8 + 44 = R1 + 52
D2 = 2 * R2
```

- 外环扇区沿 360° 均分，数量为剩余项数（1–10）。
- 外环展开时，内环 `opacity: 0.4` 且不可点，只有中心「返回」可点。
- 外环与内环共用同一个笔尖圆心。
- 圆心固定；内环按 `R1 + 16` 做窗口 clamp，外环超出窗口就裁切，不为外环重新移动圆心。
- 最多两层同心环，合计最多 19 项；超过 19 项落到浮岛「更多」面板并记录警告。

### 6.3 空隙命中

- 内外环之间有 8pt 空隙。
- 铺一层覆盖整个外环直径的透明命中盘，`pointer-events: auto`，点击空隙不做事。
- scrim 只负责圆盘之外的空白；点盘外关闭菜单。

## 7. 显示与悬停提示

- 3–6 项：图标 + 不超过 2 个字的标签。
- 7–10 项：只放图标，完整名称由悬停提示承担。
- 当前值：2px 主色描边 + 左上角小圆点；非预设值不高亮。
- 悬停：扇区填充浅主色。
- 提示框：
  - 显示「名称 · 当前值」，例如 `描边 · 当前：黑`；
  - 当前值非预设时显示真实值，例如 `描边 · 当前：#a1b2c3`；
  - 位置在最外层环之外，靠近悬停扇区的角平分线；
  - `pointer-events: none`，不拦截笔点击；
  - 贴窗口边缘时翻转方向，不裁切；
  - 笔离开扇区或环关闭时立即隐藏。

```
                          ╭────────────────╮
                          │ 描边 · 当前：黑 │
                          ╰────────────────╯
                       ┌────────┐
                       │  ◐ 描边│
            ┌──────────┴────────┴──────────┐
            │  ◑                        ◑  │
            │            ◎ 取消             │
            │  ◑                        ◑  │
            └──────────┬────────┬──────────┘
                       │   ◑    │
                       └────────┘
```

## 8. 动画规格

| 参数 | 值 |
|---|---|
| 顺序 | 从 12 点开始，顺时针按槽位顺序 |
| 槽间隔 | 14ms |
| 单槽时长 | 64ms，透明度 0→1，同时向外扩 4pt |
| 总时长上限 | ≤200ms（10 槽 190ms，9 槽 176ms） |
| 中心 | 0ms 直接出现，不参与依次显示 |

```
0ms      ◎ 中心 + ①
14ms              ②
28ms                    ③
42ms                          ④
...
126ms                               ⑩ 开始
190ms                               ⑩ 完成
```

| 状态 | 动画 |
|---|---|
| L1 打开 | 扇区依次淡入 + 向外扩 4pt |
| L1 → L2 | 整环 90ms 交叉淡入，不依次 |
| 打开外环 | 内环 90ms 降到 0.4；外环从内向外依次淡入，14ms/项，≤160ms |
| 关闭 | 立即关闭，不做退场 |
| 悬停提示 | 80ms 淡入，不做依次 |
| 应用样式 | 立即关闭，不等待动画 |

约束：

1. 命中不等动画：从第 0 帧起整环可点、可悬停。
2. 不用 JS 定时器链：每个扇区带 `--i`，CSS 用 `animation-delay: calc(var(--i) * 14ms)`，只动 `opacity` 和 `transform`。
3. 移除现有 `.ts-radial` 的 160ms `ts-radial-in` 整体缩放，避免和分槽动画叠加。
4. `prefers-reduced-motion: reduce` 时取消 stagger，整环 60ms 淡入或直接出现。
5. 截图前统一等 220ms，或加 `TS_NO_ANIM=1` 关闭动画。

## 9. 调色板（v1 固定）

- 本版本只使用 6 个固定色：黑 / 红 / 绿 / 蓝 / 橙 / 灰。
- 色值常量放在 `style-wheel.js`，不新增 `palette.js`。

## 11. Excalidraw 写入策略

优先级：

```
公开 API（updateScene / setStyle）
        │ 写不进去
        ▼
最小源码改动（Web/vendor/excalidraw）
        │ 还是不行
        ▼
记录为上游限制，不放假按钮
```

- 每条属性都先实测是否真的能写；能写才显示。
- 需要改源码时，严格按 `Docs/fork-changes.md`：
  - 每处改动带 `// TS-FORK:` 注释；
  - 在 `Docs/fork-changes.md` 登记文件、改了什么、为什么、对应需求；
  - 用 `git format-patch` 导出到 `Docs/patches/` 做兜底；
  - 不手改 `Resources/Sketch` 构建产物。
- 当前仓库用 npm 包 `@excalidraw/excalidraw@0.18.1`，而 fork 计划指向 `Web/vendor/excalidraw` submodule（目前为空）。真正需要改源码时，必须先决定 submodule 构建路径。

## 12. scrim 与层级修复

现状：`Shell.jsx:479` 先渲染 `<RadialMenu>`，`:538` 后渲染 `.ts-scrim`；两者都是绝对定位、`pointer-events: auto`，scrim 没有 `z-index`。按层叠规则，后渲染的 scrim 会盖住菜单，点扇区实际点到 scrim，直接关闭。

修法：

- `.ts-scrim`：`z-index: 60`；
- `.ts-radial`：`z-index: 70`；
- 悬停提示：`z-index: 75`，`pointer-events: none`；
- 内外环空隙命中盘放在 `.ts-radial` 内，点击不做事；
- 验收必须覆盖「真正点中扇区并生效」，不能只看菜单是否打开。

## 14. 特殊元素规则

- **锁定**：全部选中元素锁定时不弹环，浮条提示「元素已锁定」；部分锁定只改未锁定元素。
- **分组**：选中分组时改整组。
- **绑定文字**：改形状颜色 / 透明度时不自动改绑定文字；需要单独选中文字。
- **图片**：不进入样式环；混合选中时先过滤图片，剩余元素取交集；全被过滤掉时提示无可改元素。
- **撤销**：每次点选 = 一次 `setStyle` = 一次撤销，不做合并。
