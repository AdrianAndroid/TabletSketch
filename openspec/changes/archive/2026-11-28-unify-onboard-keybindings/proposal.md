# 键位统一管理：板载键卡片化与下拉选功能

## 问题

设置里存在两个入口操作同一份板载键数据：
- 「输入 → 键位」页：8 行只读文本，只显示功能名，页面注明"动作可在「布局 → 板载键」中定制"。
- 「布局 → 板载键」页：完整的拖拽排序/候选池/形态预览编辑页。

两者读写同一份 `layout.surfaces.onboardKeys.ids`，重复且割裂。

同时，窗口顶部的板载键 1~8 只有淡灰数字圆圈，按下才变蓝，看不出每个键当前绑定什么功能；而且现有按真机物理键位百分比分布，用户希望 8 键等距平分整个宽度。

## 目标

- 合并为一个入口：删除「布局 → 板载键」页，保留「输入 → 键位」页并改为编辑页——固定 8 行，每行一个下拉菜单选择功能，可选项为全部动作（工具 11 + 面板 3 + 动作 8，与右浮岛候选池一致），带图标+名称。保留「恢复默认」。
- 顶部 1~8 键改为卡片式：圆角矩形卡片外框，内左侧圆形编号、右侧当前绑定的功能图标（与右浮岛同款线条图标）。
- 常态编号与图标都淡灰、不抢画面；按下时整卡变蓝、编号与图标一起高亮。
- 8 键等距平分整条按键带宽度，不再按真机物理百分比分布。
- 卡片尺寸随 `--ts-ui-scale` 等比缩放，按键带高度保持不变，不挤占手写区。

## 用户已确认的决策

| 决策点 | 选择 |
|---|---|
| 合并入口 | 删「布局 → 板载键」，保留「输入 → 键位」改下拉编辑 |
| 下拉选项 | 全部动作库，与右浮岛一致 |
| 图标显示 | 常显但淡色，按下整卡高亮 |
| 图标位置 | 编号 + 图标横向并排（卡片内左圆右图标） |
| 键位分布 | 8 键等距平分整个宽度（不用真机物理百分比） |

## 非目标

- 不改 `layout.v2` 数据结构与配置档/导入导出/校验回落机制；下拉仍写同一份 `onboardKeys.ids`。
- 不改硬件按键与屏幕热区的执行链路（仍走 `resolveSlot → activate`）。
- 不改浮岛拖动、样式环、笔坐标映射。
- 不改变按键带高度与画布留白比例。

## 影响

- `SettingsWindow.jsx`：导航删项、`keys` 页改为 8 行下拉、保留恢复默认。
- `PadBand.jsx` + `chrome.css`：卡片化渲染、等距分布、图标与高亮、缩放。
- `Shell.jsx`：`PadBand` 需拿到当前绑定动作以渲染图标（传 ids）。
- `Tools/ui-test/main.js`：移除旧板载键页断言，新增下拉与图标/分布断言。
- 规格：`app-settings`、`pen-first-ui` 同步修订。
