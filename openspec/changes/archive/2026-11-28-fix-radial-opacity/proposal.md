# 变更：修复样式环扇区半透明透出画布

## Why

用户真机截图反馈：样式环中高亮（悬停/当前）扇区是半透明的，能看到下面的画布图案与选中框，视觉上像「没盖住」，影响操作判断。

原因是 `chrome.css` 里 `.ts-radial-path.is-hover` 使用 `--ts-accent-soft: rgba(10, 132, 255, 0.12)`；深色模式下 `.ts-radial-path` 本身也用 `rgba(44, 45, 50, 0.94)`。两种填充都带 alpha，SVG 扇区会透出底层画布内容。

## What Changes

- 为样式环单独定义不透明的浅色/深色填充色，悬停与当前高亮使用实色。
- 深色模式普通扇区改为实色填充。
- 二级样式环里内圈降低权重时不再用整体 `opacity`，改用实色底 + 图标淡化，保证不透视。
- 离屏回归新增样式环扇区填充不透明的断言。

## Impact

- 样式环打开后，所有扇区完全遮住下方画布；高亮仍然可辨，但不再透出图案。
- 亮色/深色主题都生效；其余自绘 UI 的半透明强调色保持不变。
