# 左侧样式浮动岛

## Why

侧键样式环是盲操作的径向菜单，笔尖要经过两级扇区才能到达取值项，看不到当前值、也不适合边画边调。用户需要在画布左侧有一块**常驻可见**的样式入口：选中图形后自动出现，直接看到每个类别的当前值，笔悬停即高亮、点一下展开取值，再点取值即应用。

按项目输入分层规则（R11），笔是一等输入：悬停/点击都由笔决定；鼠标仅在本应用内模拟笔。新增交互必须避免重演此前的高频重渲染与笔事件丢失问题（`optimize-input-render-performance`、`fix-island-drag-with-pen`）。

## What Changes

- 左侧新增常驻样式岛：只在有选中图元时显示；无选中时整岛隐藏。
- 样式类别与当前值直接复用 `style-wheel.js`（`categoriesFor` / `formatCurrent` / `buildLevel2`），与侧键样式环共用同一份定义，不新增样式能力。
- 交互：
  - 笔悬停某类别按钮 100ms 后高亮该按钮，不展开。
  - 笔点击类别按钮后在该按钮右侧展开该类别的取值条。
  - 笔在类别按钮与取值条之间移动不收起；离开两者 200ms 后收起。
  - 点击取值项立即应用样式并收起取值条。
- 类别按钮显示当前值预览：颜色类显示色块，其它沿用 `formatCurrent` 文本；只用现有预设，不新增自定义取色器/输入框。
- 取值条完全不透明（复用实色变量），所有控件在 `data-ts-ui` 容器内，笔事件不落到画布。
- 悬停高亮订阅 `tablet:penpos` 并用 rAF 合并，只有左侧岛挂载时才订阅；点击应用经 `setStyle` 走 Excalidraw 原生写入与撤销。
- 右侧工具岛禁止吸附到左侧：拖动时水平下限收紧到右半区。
- 压感读数板固定右上，不再随右侧工具岛换边。
- 顺手修正 `pen-first-ui` 规格中二级环内圈「降到 0.4」的过时描述（上一变更已改为实色 + 图标淡化，不改行为）。

## Impact

- 新增文件：`Web/sketch/src/tablet/LeftStyleIsland.jsx`、对应 CSS 段落。
- 修改：`Shell.jsx`（挂载左岛、工具岛禁左、读数板固定右上）、`chrome.css`、`Tools/ui-test/main.js`（新增用例）、稳定规格与索引、README 计数。
- 不改变：侧键样式环、笔事件路由、Excalidraw 原生样式写入/撤销、签名与打包链路。
- 验证：前端构建 + 离屏回归；真机笔体验由用户确认。
