# 五处布局可定制：设置面板重构

## 问题

设置面板 `SettingsWindow.jsx` 目前只有「格子数量 / 双排 / 更多方向 / 压感 / 背景」等少量控件，并且 `slotCount`、`doubleColumn`、`moreDirection` 写入后没有任何消费者，属于死设置。

用户要求以下五处的**显示按钮与排布全部可定制**：

1. 左侧样式浮动岛
2. 右侧工具浮动岛
3. 手写笔侧键 1（样式环）
4. 手写笔侧键 2（工具环）
5. 板载键 1–8

现有配置全部硬编码在 `tool-slots.js` / `tool-wheel.js` / `style-wheel.js` / `LeftStyleIsland.jsx` / `Shell.jsx`，无法编辑；样式环取值更是规格写明「v1 固定不可配置」。旧设置代码不满足需求，用户明确授权删除重构。

## 目标

- 用统一的 `layout.v2` 配置模型取代五处硬编码：每处保存有序按钮表与排布参数；同一按钮 id 的动作语义全局一致，状态显示同步。
- 样式完全开放：样式类别、顺序、每个类别的取值项（含自定义颜色）都可编辑。
- 板载键由应用拦截并完全定制：8 键原生快捷键失效，动作由应用执行；默认动作对齐原固件快捷键。
- 右岛与板载键顺序各存各的，互不影响。
- 设置面板重构为五处布局页 + 配置档页：形态预览、箭头调序、拖拽排序、候选池、排布参数；具名配置档支持保存/切换/复制/重命名/删除/导入导出。
- 配置改动即时生效，修复旧死设置。

## 非目标

- 不改变 Excalidraw 元素类型集合、序列化格式、渲染内核。
- 不改笔的输入链路与坐标映射；板载键拦截只作用于本板 VID/PID 的键盘接口，不全局监听键盘。
- 不引入账号同步；配置只存本机。
- 不改动已定稿的浮岛拖动、样式环不透明、笔优先输入仲裁等行为。

## 用户已确认的决策

| 决策点 | 选择 |
|---|---|
| 板载键 | 拦截并完全定制（应用执行动作） |
| 右岛与板载键 | 顺序各存各的，动作语义与状态显示一致 |
| 样式环 | 完全开放，含自定义颜色 |
| 排序方式 | 箭头精确调整 + 拖拽快捷排序 |
| 配置档 | 本期一起做 |

## 影响

- 新增 `Web/sketch/src/tablet/layout-config.js`：配置模型、动作库、校验、迁移、配置档存取。
- 重写 `Web/sketch/src/tablet/settings/SettingsWindow.jsx` 与设置样式。
- `style-wheel.js` / `tool-wheel.js` / `LeftStyleIsland.jsx` / `Shell.jsx` 改为读配置构建。
