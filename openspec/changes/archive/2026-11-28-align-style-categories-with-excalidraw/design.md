# 设计：按 Excalidraw 截图校准图元样式类别

## 1. 依据

用户提供的真机对照截图逐列给出了图元图标与其原生样式面板。放大核对结果如下（只列样式类，图层与操作按既有规格不进入样式环/左岛）：

| 图元 | 截图中的样式分组 |
|---|---|
| 矩形 | 描边、背景、描边宽度、边框样式、线条风格、边角、透明度 |
| 菱形 | 描边、背景、描边宽度、边框样式、线条风格、边角、透明度 |
| 椭圆 | 描边、背景、描边宽度、边框样式、线条风格、透明度 |
| 箭头 | 描边、描边宽度、边框样式、线条风格、Arrow type、端点、透明度 |
| 直线 | 描边、背景、描边宽度、边框样式、线条风格、边角、透明度 |
| 自由笔 | 描边、背景、描边宽度、透明度 |
| 文字 | 描边、字体、字体大小、文本对齐、透明度 |
| 画框 | 透明度 |
| 嵌入网页 | 同矩形 |

截图里的「端点」是一组两个独立控件（起点箭头、终点箭头）。沿用 `style-wheel.js` 现有的 `startArrow` / `endArrow` 两个类别分别呈现，仍能独立写入，且不破坏侧键环的两级结构。

## 2. 改动范围

只改 `Web/sketch/src/tablet/style-wheel.js` 中的类型到类别映射表 `TYPE_CATEGORIES` 及其引用的常量数组：

- `SHAPE` 保持不变，供矩形 / 菱形 / 嵌入网页使用。
- 新增 `ELLIPSE`：从 `SHAPE` 去掉 `roundness`。
- 新增 `LINE`：描边、背景、描边宽度、边框样式、线条风格、`roundness`、透明度。
- `ARROW`：去掉 `background`，保留 `arrowType` / `startArrow` / `endArrow`。
- `FREEDRAW`：加入 `background`。
- `TEXT`、`FRAME` 保持不变。

`categoriesFor` 仍按 `ORDER` 过滤并取多选交集；`buildLevel1`、`buildLevel2`、`buildCategoryButtons`、`buildValueItems` 自动继承新映射，不改调用方。

## 3. 兼容性

- `strokeStyle`、`roughness` 等类别本身的取值与 `patch` 不变，径向菜单仍满足「3–6 项显示不超过两个字标签」的规格。
- 用户已保存的画板不受影响；变更只影响控件可见性，不改现有元素字段。
- 未来如要加入截图中的「图层」「操作」，须另立变更，因为现有规格明确要求它们不进入样式环。

## 4. 验证

- 用 Node 直接导入纯函数模块，对每种图元类型断言 `categoriesFor([type])` 的精确类别列表，并断言混合选中取交集。
- 跑现有离屏 Electron 回归，确认左岛悬停、展开、写入、收起行为未回归。
- 按 R12 构建、固定身份签名覆盖安装并启动，真机用笔分别选中椭圆、直线、箭头、自由笔核对左岛类别。
