# 按 Excalidraw 截图校准图元样式类别

## Why

用户用真机截图逐列对照了 Excalidraw 各图元的原生样式面板，指出左侧样式岛与侧键样式环显示的样式类别和截图不一致。当前 `style-wheel.js` 与稳定规格沿用了早期对截图的误读：椭圆带有「边角」、直线带有起点/终点箭头却没有「边角」、箭头带有「背景」、自由笔缺少「背景」。这会让笔在选中图元后看到不该有的样式入口，或找不到原生面板里存在的样式入口。

## What Changes

- 按截图把图元类型与样式类别的映射修正为：
  - 矩形 / 菱形：描边、背景、描边宽度、边框样式、线条风格、边角、透明度
  - 椭圆：描边、背景、描边宽度、边框样式、线条风格、透明度（无边角）
  - 直线：描边、背景、描边宽度、边框样式、线条风格、边角、透明度（无箭头端点）
  - 箭头：描边、描边宽度、边框样式、线条风格、Arrow type、起点箭头、终点箭头、透明度（无背景）
  - 自由笔：描边、背景、描边宽度、透明度
  - 文字、画框、嵌入网页沿用现有定义
- 更新 `openspec/specs/pen-first-ui` 的「图元样式维度清单」，使规格与实现都反映截图对应关系。
- 增加按图元类型断言类别集合的回归，覆盖左岛与侧键样式环共用的 `categoriesFor`。

## Capabilities

- `pen-first-ui`：图元样式维度清单、左侧样式岛、侧键两级样式环。

## Impact

- 选中椭圆、直线、箭头、自由笔后，左岛与侧键环的一级类别会变化；取值项本身的写入逻辑不变。
- 混合选中仍按类型取类别交集，多选行为不变。
- 图层与操作仍不作为样式项进入环或左岛，继续走浮岛「更多 → 原生右键菜单」。

## 非目标

- 不新增样式属性，也不改 Excalidraw 的样式写入与撤销行为。
- 不调整径向菜单的两字标签长度、扇区布局和动画。
- 不把截图中的「图层」「操作」两组搬进样式岛。
- 不改鼠标模拟层或输入分层规则。
