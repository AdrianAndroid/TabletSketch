# 左侧样式岛悬停即弹出取值条

## Why

左侧样式岛最初的需求是「手写笔经过样式对应的按钮，自动弹出对应的选择；手写笔点击选中」。实现时被收敛成「悬停只高亮、点击才展开」，导致真机上笔停在类别按钮上时右侧没有任何取值条弹出（只有高亮与文字提示），与笔的操作直觉不符。

按项目输入分层规则（R11），笔是一等输入，交互以笔的体验为准；鼠标只是本应用内模拟笔。因此把左岛的展开触发改回悬停驱动。

## What Changes

- 笔（或模拟笔的鼠标）悬停某类别按钮满 100ms：高亮该按钮 **并同时在该按钮右侧展开该类别的取值条**。
- 点击类别按钮：改为幂等「确保展开」，不再 toggle 收起（避免悬停已展开后被点击反而收起）。
- 点击取值项：立即应用样式并收起取值条，行为不变。
- 笔在类别按钮与取值条之间移动不收起、离开两者 200ms 后收起，行为不变。
- 性能约束不变：订阅 `tablet:penpos` / `tablet:mousepos` 经 rAF 合并，只有「高亮 key」或「展开 key」变化才 setState。

## Impact

- 修改：`Web/sketch/src/tablet/LeftStyleIsland.jsx`（悬停定时器回调、点击处理）、`Tools/ui-test/main.js`（悬停展开断言）。
- 同步：`pen-first-ui` 稳定规格中「笔悬停高亮」「点击展开取值条」两个场景。
- 不改变：CSS 布局与取值条定位、侧键样式环、笔事件路由、Excalidraw 原生写入/撤销、签名与打包链路。
- 验证：前端构建 + 离屏回归；真机笔体验由用户确认。
