# 拖拽排序实时预览：所见即所得，落坑才保存

## 问题

设置面板五处布局页的「当前按钮」列表支持拖拽排序，但当前实现是：`onDragStart` 记住来源索引，拖动过程中不反馈任何视觉变化，`onDrop` 时才一次性重排并 `saveLayout`。

用户反馈：**拖动排序的时候看不到排序后的效果**，只能松手后才知道放哪，容易放错位置、反复试。期望「拖动中实时看到排序后的效果，落坑（松手）才保存排序」。

## 目标

- 拖动过程中，把被拖条目从原位置取出、按当前悬停目标位置实时插入：列表项即时让位，「形态预览」区同步显示排好后的布局。
- 松手落在某个位置时，才把预览的顺序真正写入 `layout.v2` 并广播。
- 拖到面板外、按 Esc 等方式取消拖动时，恢复拖动前的原始顺序，不写入配置。
- 保留原有上移/下移按钮，两种方式写入同一份顺序数据。
- 输入方式不变：仍复用设置面板现有的拖动入口，鼠标与笔的模拟分层约定不受影响。

## 非目标

- 不改变 `layout.v2` 的数据结构、校验与配置档机制。
- 不引入第三方拖拽库；沿用 HTML5 drag 事件，避免改动输入层。
- 不改浮岛拖动、样式环、画布与手写板坐标映射。
- 不改变「箭头精确移动」的行为与保存时机。

## 用户已确认的决策

| 决策点 | 选择 |
|---|---|
| 实时预览范围 | 列表项实时让位 +「形态预览」区同步更新 |
| 保存时机 | 松手落坑时写入配置，取消拖动不落盘 |

## 影响

- `Web/sketch/src/tablet/settings/SettingsWindow.jsx`：`SlotChip` / `Preview` / `LayoutPage` 的拖拽逻辑与渲染数据源。
- `Web/sketch/src/tablet/chrome.css`：拖动中源项、目标位、让位过渡的样式。
- `Tools/ui-test/main.js`：追加拖拽实时预览与落坑保存的离屏回归。
- 规格：`app-settings` 修订排序方式场景。
