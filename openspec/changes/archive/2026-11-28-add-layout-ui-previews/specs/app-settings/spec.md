## ADDED Requirements

### Requirement: 布局页真实 UI 预览

左浮动岛 / 右浮动岛 / 笔键 1 / 笔键 2 四页 SHALL 在顶部展示与真机 UI 高度仿真的图形预览，替换旧的纯文字形态描述；预览 SHALL 复现该面的几何形态、动作图标、当前态与「更多」占位。板载键页 SHALL NOT 在本变更内增加 UI 预览。

#### Scenario: 各页预览形态

- **WHEN** 用户打开任一受支持的布局页
- **THEN** 页面顶部 MUST 显示该面的图形预览
- **AND** 左岛预览 MUST 为竖排样式按钮条（图标 + 当前值文本）
- **AND** 右岛预览 MUST 为图标网格，列数 MUST 与真机一致按「格子总数 > 10 才双列」判定，尾部 MUST 有「更多」
- **AND** 笔键 1 / 笔键 2 预览 MUST 为 SVG 扇区环，含内圈、固定「更多」扇区与外圈
- **AND** 每个槽位 MUST 显示对应动作的图标（样式类别可显示色块）并反映当前态

#### Scenario: 预览与配置同步

- **WHEN** 用户增删 / 重排按钮，或切换配置档
- **THEN** 预览 MUST 按当前显示顺序重新渲染
- **AND** 预览 SHALL 只读展示，MUST NOT 派发任何真实动作

### Requirement: 预览上直接拖动重排

预览中的每个配置槽位 SHALL 可作为拖动源与落坑目标，与「当前按钮」列表共用同一份拖动预览态；拖动中两处同步更新，松手落坑才持久化。

#### Scenario: 预览内拖动

- **WHEN** 用户在预览上按住一个槽位拖到另一个槽位上方
- **THEN** 预览与列表 MUST 都以「松手后会得到的顺序」实时更新
- **AND** `layout.v2` MUST NOT 在拖动中被写入

#### Scenario: 预览松手落坑

- **WHEN** 用户在预览上松手落在目标坑位
- **THEN** 新顺序 MUST 写入 `layout.v2` 并广播
- **AND** 预览与列表 MUST 显示已保存的新顺序

#### Scenario: 预览取消拖动

- **WHEN** 用户把预览槽位拖到面板外松手，或按 Esc 取消
- **THEN** 预览与列表 MUST 回退到拖动前顺序
- **AND** `layout.v2` MUST NOT 被写入

#### Scenario: 非配置槽位不可拖

- **WHEN** 用户尝试拖动环预览的「更多」扇区
- **THEN** 该扇区 MUST NOT 作为拖动源参与重排
