# proposal · unify-virtual-pen-cursor

## Why

这个应用只为一支手写板服务，鼠标是「在上层带动虚拟笔」的补充输入，不是另一套光标体系。

现在的实现给鼠标单独做了 6pt 小圆点，和手写笔的 14pt 圆环 / 十字是两套指示器。用户要的是**一套指示器**：鼠标移动时，手写板那个圆圈跟着走；操作时变 `+`；鼠标只多一个右键模拟侧键 1。

## What Changes

- 删除鼠标专属的 `.ts-mouse-dot`，鼠标与手写笔共用同一个 `.ts-pen-cursor`。
- 指示器位置取「最后活动的输入源」：笔 hover / 落笔用 HID 映射坐标，鼠标移动用 `clientX/Y`。
- 指示器形态只看当前工具：绘图类 `+`，选择 / 平移 14pt 圆环，橡皮圆圈；落笔收成实心 / 加粗。
- 系统鼠标箭头保持原样，不设置 `cursor: none`，不替换光标。
- 鼠标右键 / `\` 仍映射侧键 1，不改。

## Capabilities

- `pen-input`：统一虚拟笔输入补「指示器共用」。
- `pen-first-ui`：工具光标改为单一指示器。

## Impact

- 只改 `Shell.jsx` 的光标状态与 `chrome.css`；不改虚拟笔坐标、压力、仲裁。
- 无新增依赖，不影响 `MacAppControlDeck`。

## 非目标

- 不区分鼠标 / 手写笔光标皮肤。
- 不做鼠标悬停 UI 时不显示指示器。
