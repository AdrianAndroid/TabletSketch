# design · add-mouse-input

## 1. 目标

鼠标和手写板共用同一支虚拟笔：

```
来源：
  手写板  HID 坐标 → 归一化 → 映射进 .ts-stage
  鼠标    clientX/Y → 相对 .ts-stage 归一化；绘制时夹到边界

        ↓ 同一套事件
  hover / began / changed / ended

        ↓
  applyHidEvent → 画布 / 自定义 UI
```

不新增「鼠标模式」。鼠标只是另一个输入源。

## 2. 统一虚拟笔

| 来源 | 坐标 | 压力 | 悬停指示 | 绘制范围 |
|---|---|---|---|---|
| 手写板 | HID 归一化后映射进 `.ts-stage` | 真实压感 | 14pt 空心环 / 8pt 实心，限制在手写区 | `.ts-stage` |
| 鼠标 | `clientX/Y` 相对 `.ts-stage` 归一化 | 固定 0.5 | 小圆点，可跟随到应用内任意位置 | `.ts-stage` |

两者都产生相同的 `pen` 事件：

```
{ t: "pen", ph: "hover" | "began" | "changed" | "ended",
  x: 0..1, y: 0..1, p: 0..1 }
```

## 3. 鼠标行为

```
鼠标移动
  ├─ 在应用内 ──▶ 小圆点跟随；系统箭头保留
  └─ 移出应用 ──▶ 小圆点隐藏；鼠标不被锁定

鼠标左键
  ├─ 在 .ts-stage 内 ──▶ 虚拟笔 began / changed / ended
  ├─ 在自定义 UI 上 ──▶ 原生点击 UI，不落笔
  └─ 拖出 .ts-stage ──▶ 坐标夹到边界，笔触停在边界

鼠标右键 / \
  └─ 打开样式环，圆心取鼠标位置；抑制原生右键菜单
```

细节：

- 鼠标输入固定压力 `0.5`；不模拟压感，不按速度改线宽。
- 画布上的原生鼠标事件必须拦截，避免和注入的虚拟笔重复绘制。
- 自定义 UI（浮岛、菜单、样式环、设置、文本输入框）上的鼠标事件不拦截。
- 鼠标移出窗口时，如果正在绘制，按最后夹取点结束笔画，避免卡住。
- 小圆点 `pointer-events: none`，不挡任何点击。
- 小圆点在样式环打开时保留，作为瞄准点；`pointer-events: none`，不挡点击。

## 4. 手写板行为不变

- 笔坐标仍只映射进 `.ts-stage`。
- 笔触圆圈仍只出现在手写区内；按键带、浮岛、窗口留白上不出现。
- 侧键 1 / 侧键 2 行为不变。
- 板载键识别与高亮不变。
- 压感、倾斜、橡皮不变。

## 5. 输入仲裁

同一时刻只允许一个来源写画布（R3.5）。

```
空闲
  ├─ 手写板 hover / began ──▶ activeSource = pen
  └─ 鼠标 hover / 左键 ────▶ activeSource = mouse

笔画进行中
  ├─ 只接受 activeSource 的 changed / ended
  ├─ 另一来源的 began / changed 被忽略
  └─ 鼠标点击 UI 仍然有效

笔画结束
  └─ 回到空闲；最后活动的来源下一次生效
```

规则：

- 不提供手动模式切换。
- 鼠标点击 UI 不属于「写画布」，任何时刻都放行。
- 手写板侧键与鼠标右键都映射到侧键 1，不参与画布仲裁。

## 6. 光标与小圆点

| 来源 | 悬停 | 落笔 | 范围 |
|---|---|---|---|
| 手写板 | 14pt 空心环 | 8pt 实心 | 只在 `.ts-stage` |
| 鼠标 | 6pt 小圆点 | 8pt 实心 | 应用内任意位置；移出窗口隐藏 |

- 系统箭头始终保留，不设置 `cursor: none`。
- 小圆点用独立元素 `.ts-mouse-dot`，`pointer-events: none`，层级在自定义 UI 之上、样式环之下。
- 小圆点不参与命中测试。

## 7. 笔触边界

鼠标可以自由移动，只有笔触受限。

```
鼠标在 .ts-stage 内        → 正常出墨
鼠标在 .ts-stage 外        → 不出墨，小圆点继续跟随
按住左键拖出 .ts-stage     → 坐标夹到边界，笔触停在边界
拖回 .ts-stage 内          → 从边界继续
```

- 夹取只作用于虚拟笔坐标，不作用于系统光标。
- 越界夹取使用 `clamp01((clientX - rect.left) / rect.width)`，`rect` 为 `.ts-stage`。
- 手写板仍使用原有映射，不做鼠标式夹取。

## 8. 样式环入口

| 入口 | 行为 |
|---|---|
| 鼠标右键 | 打开样式环；抑制原生菜单 |
| `\` | 打开样式环，使用最后一次鼠标位置 |
| 浮岛「更多 → 样式环」 | 打开样式环 |
| 菜单栏「视图 → 样式环」 | 打开样式环；无鼠标位置时用窗口中心 |
| 手写板侧键 1 | 原有行为不变 |

- 无选中：提示「先选中图形」，不打开。
- 环打开时：右键 / `\` / 侧键 1 都不响应。
- 环只做窗口内 clamp；鼠标本身不 clamp。
- 鼠标可自由移动到扇区并点击；小圆点不挡点击。
- 原生右键菜单被样式环占用；图层与链接走浮岛「更多 → 原生右键菜单」。

## 9. 状态显示

- 不提供「鼠标模式 / 手写板模式」切换。
- 顶部条只显示手写板连接状态：
  - `手写板已连接`
  - `未检测到手写板`
  - `缺少输入监控权限`
- 鼠标输入始终可用，不需要额外开关。

## 10. 实现边界

| 文件 | 职责 |
|---|---|
| `Web/sketch/src/tablet/mouse-input.js`（新增） | 鼠标事件 → `pen` 事件；右键 / `\`；小圆点位置；边界夹取；移出窗口处理 |
| `Web/sketch/src/tablet-sketch.js` | 统一笔事件入口；画布原生鼠标事件拦截；HID 与鼠标共用 `applyHidEvent` |
| `Web/sketch/src/tablet/Shell.jsx` | `.ts-mouse-dot` 渲染；按鼠标位置打开样式环；连接状态 |
| `Web/app/main.js` | 菜单栏「视图 → 样式环」 |
| `Web/app/preload.js` | 转发 `ts:open-style-ring` |
| `Web/sketch/src/tablet/chrome.css` | `.ts-mouse-dot` 样式与层级 |

实现约束：

- 画布上捕获 `pointerType === "mouse"` 的按下 / 移动 / 抬起，阻止原生绘制，改走虚拟笔。
- `[data-ts-ui]` 上的鼠标事件不拦截。
- 鼠标路径不调用 `CanvasMapping`，不读写 `penPos` 作为绘制坐标。
- 手写板路径不经过鼠标夹取逻辑。

## 11. 无设备测试

1. 无手写板启动，鼠标移动出现小圆点，系统箭头仍在。
2. 鼠标在画布、按键带、浮岛、菜单之间自由移动；不被夹取、不被锁定。
3. 鼠标移出窗口，小圆点隐藏；移回来恢复。
4. 左键在画布上拖动出墨；拖出 `.ts-stage` 后笔触停在边界；拖回继续。
5. 左键在浮岛 / 菜单上点击正常，不落笔。
6. 右键打开样式环，圆心为鼠标位置；鼠标可自由移动到扇区并点击。
7. `\` 与浮岛「更多 → 样式环」同样可用。
8. 手写板 mock：笔悬停时圆圈只在 `.ts-stage`；鼠标移动不产生笔迹。
9. 两个来源同时操作：一笔进行中，另一来源不抢画布。
10. 鼠标双击编辑文字、选中手柄、拖拽元素必须验证；若虚拟笔破坏双击，需补 `click` / `dblclick` 合成。
11. 离屏 Electron：`sendInputEvent` 鼠标事件 + `capturePage`，`show: false`。

## 12. 风险与处理

| 风险 | 处理 |
|---|---|
| 画布原生鼠标被拦截后，双击编辑文字失效 | 合成 `click` / `dblclick`，或对文本工具放行原生鼠标 |
| 鼠标拖出窗口收不到 `mouseup` | 在 window / blur 上兜底结束笔画 |
| 小圆点遮挡 UI 点击 | `pointer-events: none`，层级低于样式环 |
| 鼠标与笔同时 hover 抢 activeSource | 只在空闲时更新 activeSource；笔画进行中锁定发起源 |
| 右键被样式环占用，原生菜单不可达 | 浮岛「更多 → 原生右键菜单」提供入口 |
