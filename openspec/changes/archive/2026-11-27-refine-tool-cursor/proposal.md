# proposal · refine-tool-cursor

## Why

参考 Draw 类绘图应用的光标规则：**光标形态由工具决定，系统箭头不隐藏**。

当前实现不管选了什么工具，鼠标都是小圆点、笔都是圆环。选中矩形 / 箭头 / 笔刷时看不到「落点」提示，画线像盲画。

## What Changes

- 绘图类工具（自由笔、矩形、菱形、椭圆、箭头、直线、文字、图片）激活时，笔尖指示器显示 **十字准星 `+`**；选择 / 平移仍用圆环，橡皮保留圆圈。
- 鼠标：保留系统箭头，`+` 由箭头带动，不设置 `cursor: none`，不替换光标。
- 手写笔：悬停指示器同样按工具切换 `+` / 圆环，圆环仍是原来的 14pt 空心、落笔 8pt 实心。
- 只改指示器造型与跟随逻辑，不改虚拟笔坐标、压力与输入仲裁。

## Capabilities

- `pen-first-ui`：新增「工具光标」。

## Impact

- 只改 `Shell.jsx` 的光标 class 与 `chrome.css` 的指示器样式。
- 不新增依赖，不改 Excalidraw 源码，不影响 `MacAppControlDeck`。

## 非目标

- 不做橡皮半径实时缩放、不做工具自定义光标、不做菜单栏光标主题。
- 不隐藏或替换系统鼠标箭头。
